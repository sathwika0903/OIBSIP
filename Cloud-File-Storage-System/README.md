# Cloud File Storage System

## About the Project

CloudVault is a responsive cloud file storage system landing page designed to provide a simple and modern interface for storing, organizing, and accessing files.

This project was created as part of the Oasis Infobyte Web Development & Designing Internship – Level 1 Task 1.

## Objective

The objective of this project is to create a visually polished and responsive landing page using HTML5 and CSS3.

## Technologies Used

- HTML5
- CSS3

## Features

- Sticky navigation bar
- Navigation links for Home, Features, About, and Contact
- Hero section with headline, subheadline, and call-to-action buttons
- Cloud storage feature section
- Secure files feature section
- Easy access feature section
- About section
- Call-to-action section
- Footer with contact and social links
- Responsive design for desktop, tablet, and mobile screens
- Clean and modern user interface
- Semantic HTML5 structure
- CSS-only design without JavaScript

## Sections

### 1. Navigation

Provides easy access to different sections of the landing page.

### 2. Hero Section

Introduces the CloudVault cloud storage concept with clear call-to-action buttons.

### 3. Features

Highlights cloud storage, secure files, and easy file access.

### 4. About

Explains the purpose and design concept of the CloudVault project.

### 5. Call to Action

Encourages users to get started with the cloud storage concept.

### 6. Footer

Contains project branding, navigation links, email, and social links.

## Responsive Design

The landing page is designed to work across:

- Desktop
- Tablet
- Mobile

CSS media queries, Flexbox, and CSS Grid are used to create a responsive layout.
